# RPA Engineering

> Conhecimento prático sobre engenharia de RPA com Python, UiPath e automação de navegadores.

Este repositório reúne padrões, decisões técnicas, estudos de troubleshooting e exemplos reutilizáveis construídos a partir de experiência prática com automações. Todo o material foi preparado para uso público: exemplos usam dados fictícios e não representam ambientes ou processos reais.

**English summary:** Practical notes, engineering patterns, troubleshooting guides, and safe examples for RPA development with Python, UiPath, and browser automation.

## Princípios

- Verificar o efeito esperado, não apenas a ausência de exceção.
- Preferir seletores e APIs estáveis a coordenadas ou esperas arbitrárias.
- Separar regras de negócio, configuração, segredos e execução.
- Registrar causa raiz, validação e limites das soluções.
- Usar exemplos mínimos, reproduzíveis e sem dados reais.
