# Como contribuir

Correções técnicas, melhorias de clareza e novos exemplos são bem-vindos.

Antes de enviar uma contribuição:

1. Use apenas dados fictícios e reproduzíveis.
2. Remova nomes de clientes, URLs internas, IPs, credenciais, identificadores e caminhos pessoais.
3. Explique o problema, a abordagem e como o resultado foi validado.
4. Cite documentação oficial quando a solução depender de comportamento específico de uma ferramenta.
5. Não inclua código ou documentação pertencente a terceiros sem autorização compatível.
