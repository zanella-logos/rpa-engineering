# Segurança e divulgação responsável

Este repositório não deve conter credenciais, dados pessoais, informações de clientes ou detalhes de ambientes privados.

Se encontrar uma informação sensível, não abra uma issue pública com o valor encontrado. Entre em contato pelo perfil do autor no GitHub e informe apenas o arquivo e a natureza do problema.

Exemplos deste repositório usam valores fictícios. Eles devem ser adaptados às políticas de segurança e ao ambiente de cada organização antes do uso.
