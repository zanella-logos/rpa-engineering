# Camofox Browser em automações

Camofox Browser é um navegador voltado à automação por agentes e baseado no Firefox. Migrações devem considerar sua API e seu comportamento reais, sem reproduzir artificialmente a arquitetura de Selenium ou de outro framework.

## Diretrizes

- Consulte a documentação e o repositório oficiais antes de usar recursos específicos.
- Identifique dependências diretas do framework anterior.
- Substitua cada interação por um recurso nativo equivalente.
- Mantenha wrappers somente quando resolverem um problema reutilizável.
- Valide navegação, download, diálogos e encerramento do navegador.

Referência: <https://github.com/jo-inc/camofox-browser>
